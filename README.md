# QUANTUM MOTORS — QMM Racing (M24.9e)

A top-down neon street racer set in the Activated Melanin Hood. Drift the blacked-out Quantum Motors muscle car, charge **M24.9e** in the slides, burn it for a glowing surge, and beat the pack to the line. At night the hood activates — payouts double.

**Quantum Melanin Media** · Robert Hadden Jr. & Mahal Kita · built with Claude

## Play

Open `index.html` in a modern browser, or play the hosted build on itch.io / CrazyGames.

## Controls

| Key | Action |
|-----|--------|
| ◄ ► / A D | Steer |
| **SPACE** (hold) | **Drift / e-brake** — steer *into* the slide to hang the tail out, *counter-steer* to tighten & catch it |
| **SHIFT** | Burn M24.9e boost (charged by drifting) |
| ↓ / S | Brake |
| H | Toggle cops · T | Turn guide · L | Lite/Full graphics · J | Next song · N | Night · W | Wet · P | Pause · M | Mute |

On mobile, steer with the on-screen analog joystick.

## Features

- **Asphalt-style sustained drift** — hold the handbrake and skate the corner, tail hung out, fully controllable via tail-steer.
- **Studio-grade procedural V8** (WebAudio, no samples) — exhaust pipe resonance that sweeps with the revs, dual sub-bass, and a Haas stereo widener for headphone immersion.
- 10 selectable cars with tuned stats + garage upgrades.
- 7 tracks — oval, S-curve serpents, a figure-8 bridge with a jump ramp, and a point-to-point cross-country stage.
- NFS-Heat-style Eraser Patrol, drift chains, boost capsules, day/night + wet weather.
- Runs on low-end rigs (LITE graphics mode) up through a photoreal FULL tier.

Single self-contained `index.html` — no build step, no dependencies.
